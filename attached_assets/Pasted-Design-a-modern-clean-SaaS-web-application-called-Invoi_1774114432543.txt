# PROJECT BRIEF — InvoiceFlow SaaS

## Overview
Build a full-stack SaaS web application for Indian shopkeepers and freelancers
to create professional PDF invoices, manage customers, track sales, and share
invoices instantly via WhatsApp (as actual PDF file) or Email. The MVP should
be simple, fast, and mobile-friendly. No GST computation logic required at launch.

### 7. Invoice Sharing (Web Share API — PDF as File)

#### CORE APPROACH: navigator.share() with PDF File
The app uses the browser-native Web Share API to share the actual PDF
file — not a link. This opens the native OS share sheet on mobile where
the user can pick WhatsApp, and the PDF is delivered as a real file
attachment in the chat.

#### Share Modal Options:

**A. WhatsApp (Primary — Mobile)**
- Fetch PDF blob: GET /api/invoices/pdf/[id]
- Create File object from blob:
  new File([blob], "Invoice-INV001.pdf", { type: "application/pdf" })
- Trigger native share sheet:
  navigator.share({
    title: "Invoice INV-001",
    text: "Hi [Customer Name], please find your Invoice INV-001
           for ₹[Total]. Due date: [Due Date]. — [Shop Name]",
    files: [pdfFile]
  })
- Always check navigator.canShare({ files: [pdfFile] }) before calling
- This opens WhatsApp (or any app) with the PDF attached as a real file
- The customer receives the PDF directly in their WhatsApp chat

**B. Desktop / Unsupported Browser Fallback**
- If navigator.canShare is not supported or files sharing not supported:
  - Auto-trigger PDF download to device
  - Show toast notification:
    "PDF downloaded! Open WhatsApp and attach the file to send it."
  - Optionally show a QR code that opens the invoice on their phone
    so they can share from mobile

**C. Email**
- Pre-fill recipient from customer's saved email address
- Call POST /api/invoices/[id]/send-email
- Server fetches PDF, attaches it to email via Resend API
- Subject: "Invoice [INV-001] from [Shop Name]"
- Body: Professional HTML email with invoice summary + PDF attached
- On success: toast "Invoice emailed to [customer email]"
- Allow editing the email address before sending

**D. Copy Link**
- Copy public invoice view URL to clipboard: /invoice/public/[token]
- Toast: "Link copied to clipboard!"
- Public page shows invoice in read-only view (no auth required)

**E. Download PDF**
- Fetch PDF blob and trigger browser download
- Filename: Invoice-[number]-[ShopName].pdf

#### Share Modal UI:
- Mobile: Bottom sheet (slides up from bottom of screen)
- Desktop: Centered modal dialog
- Each option is a large tappable card with icon + label + subtext

## SHARING IMPLEMENTATION DETAIL

### /lib/share/webShare.ts

export async function shareInvoiceAsPDF({
  invoiceId,
  invoiceNumber,
  customerName,
  total,
  dueDate,
  shopName
}: ShareInvoiceParams) {

  // Step 1: Fetch PDF from generation endpoint
  const response = await fetch(`/api/invoices/pdf/${invoiceId}`);
  const blob = await response.blob();

  // Step 2: Create a named File object
  const file = new File(
    [blob],
    `Invoice-${invoiceNumber}.pdf`,
    { type: "application/pdf" }
  );

  // Step 3: Pre-filled WhatsApp message
  const message = `Hi ${customerName}, please find attached Invoice ` +
    `${invoiceNumber} for ₹${total}.` +
    `${dueDate ? ` Due date: ${dueDate}.` : ""} — ${shopName}`;

  // Step 4: Check support and trigger native share sheet
  if (navigator.canShare && navigator.canShare({ files: [file] })) {
    await navigator.share({
      title: `Invoice ${invoiceNumber}`,
      text: message,
      files: [file],
    });
    return { success: true, method: "native" };
  }

  // Step 5: Fallback — download PDF
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url;
  a.download = `Invoice-${invoiceNumber}.pdf`;
  a.click();
  URL.revokeObjectURL(url);

  return { success: true, method: "download" };
}
